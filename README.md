# D'Ennita — Tienda Online

Aplicación web de e-commerce para la tienda D'Ennita, desarrollada con **Laravel 12** y **Vite**.

## ¿Qué es?

Plataforma de compras online que permite explorar y agregar al carrito productos de distintas categorías: cervezas, licores, comidas, bebidas, antojos, helados y despensa.

## Funcionalidades

- Catálogo de productos por categoría
- Carrito de compras (agregar/quitar productos)
- Sistema de autenticación
- Perfil de cuenta
- Soporte multilenguaje (ES/EN/PT)
- Modo oscuro/claro

## Instalación

```bash
cp .env.example .env
php artisan key:generate
npm install
composer run dev
```

## Tecnologías

- Laravel 12
- Tailwind CSS
- Vite
- SQLite
